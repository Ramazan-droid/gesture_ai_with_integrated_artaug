
# Hand Gesture Classification with ArtAug-Generated Data

A three-class hand-gesture classifier built with transfer learning (ResNet18, ImageNet-pretrained) and OpenCV. The project compares training on real images with training that also includes synthetic gesture images generated by **FLUX.1-dev + the ArtAug LoRA**.

## Overview

The project has two parts:

1. **Baseline classifier** (`advancedmodel.py`): ResNet18 with a frozen backbone and a new classification head, trained on real images with OpenCV-based augmentation.
2. **Synthetic data generation** (`generate_synthetic.py`): creates additional labeled hand-gesture images with FLUX.1-dev + ArtAug LoRA, varying lighting, composition and background. The generated images are combined with the real training split by `assigment2_model.py`.

ArtAug is a LoRA used by the image generator. It does not modify the classifier architecture.

```
real images ──────────────────────────────┐
                                           ├─► train split ─► ResNet18 ─► test on real images only
FLUX.1-dev + ArtAug ─► synthetic images ──┘

```

## Project structure

```
gesture_ai_with_integrated_artaug/
├── advancedmodel.py             # baseline model training
├── assigment2_model.py          # training with real + synthetic images
├── assignment2_eval.py           # evaluation and metrics
├── generate_synthetic.py         # FLUX.1-dev + ArtAug image generation
├── data/
│   ├── raw/                      # real images, one folder per gesture class
│   └── synthetic/                # generated images, matching class folders
├── trslearningmodel.pth          # included checkpoint
├── ArtAug_model_weights.pth      # included checkpoint
└── DiffSynth-Studio/             # clone separately for generation
```

Synthetic class folder names must match the real class folder names.


## Requirements

- Python 3.10 or 3.11 recommended (3.13 may cause dependency build errors)
- PyTorch; CUDA is optional for classifier training. The published generator is configured for CPU and generation may be slow
- `opencv-python`, `numpy`, `torchvision`, `scikit-learn`, `matplotlib` (evaluation)
- `diffsynth` / DiffSynth-Studio (synthetic image generation)
- Plenty of free disk space (FLUX.1-dev weights are many GB)

```bash
pip install torch torchvision opencv-python numpy scikit-learn matplotlib
```

## Installation: DiffSynth-Studio and model weights

The model weights are not stored in the repository. DiffSynth-Studio downloads the FLUX.1-dev model and ArtAug LoRA when the generation script runs.

**1. Clone DiffSynth-Studio next to the project directory (not inside the data folders):**

```bash
cd compvision
git clone https://github.com/modelscope/DiffSynth-Studio.git
cd DiffSynth-Studio
```

**2. (Recommended) create a virtual environment:**

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux / macOS
```

**3. Install DiffSynth-Studio:**

```bash
pip install -e .
```

If the build fails with `ModuleNotFoundError: No module named 'pkg_resources'`, install an older setuptools and build without isolation:

```bash
python -m pip install "setuptools<81" wheel
pip install -e . --no-build-isolation
```

Alternatively, skip the install: run `pip install -r requirements.txt` and run your scripts from inside the `DiffSynth-Studio` folder.

**4. Download the weights (happens on first run).** The published generator contains a Windows-specific absolute output path. Update `OUT_DIR` in `generate_synthetic.py` to your local `data/synthetic` folder before running. It currently creates 5 images per class on CPU; adjust `IMAGES_PER_CLASS` if needed.

```bash
python ..\generate_synthetic.py
```

On first run this downloads:

| Weights | Source |
|---|---|
| FLUX.1-dev (base text-to-image model) | `black-forest-labs/FLUX.1-dev` (ModelScope / Hugging Face) |
| ArtAug LoRA (`merged_lora.safetensors`) | `DiffSynth-Studio/ArtAug-lora-FLUX.1dev-v1` (ModelScope), mirrored on Hugging Face as `ECNU-CILab/ArtAug-lora-FLUX.1dev-v1` |

Notes:
- FLUX.1-dev may require accepting its license (and logging in with `huggingface-cli login`) if downloading from Hugging Face.
- The generation script depends on the DiffSynth-Studio API. If its imports fail, check the ArtAug example and installation instructions for the version you installed.

## Usage

Before running the scripts, update their hard-coded Windows dataset, output, and checkpoint paths to match your machine. The dataset should contain one subfolder per class.

**1. Train the baseline (real data only):**

```bash
python advancedmodel.py
```

The script trains on the real dataset and saves a model checkpoint.

**2. Generate synthetic images:**

Edit `CLASS_PROMPTS` in `generate_synthetic.py` to describe your classes, then:

```bash
cd DiffSynth-Studio
python ..\generate_synthetic.py
```

Prompts are built from combinations of lighting, composition and background templates. The default gesture classes are `fist`, `peace`, and `stop`; keep these names aligned with the real dataset folder names.

**3. Train with real and synthetic data:**

```bash
python assigment2_model.py
```

This script concatenates the synthetic dataset with the real training split. The current repository code does not apply baseline-confidence filtering, so review generated images and class labels before training.

**4. Evaluate and compare:** run `assignment2_eval.py` after setting the checkpoint paths and data path in its configuration. It reports accuracy, precision, recall and F1 on the real test split.

## Evaluation protocol

- Each training script creates a 70/15/15 train/validation/test split from the real dataset using seed 42. Synthetic images are appended to the training subset in `assigment2_model.py`.
- Validation and test sets contain real images only.
- Change one thing per experiment so improvements can be attributed correctly.

| Experiment | Test accuracy |
|---|---|
| Baseline (real only) | 99.12%* |
| + synthetic (ArtAug) | 99.12%* |
| + unfreeze `layer4` | Not reported |

*Reported in the repository's `test_metrics.txt`; reproduce with the same dataset and split before drawing conclusions.

## Limitations

- ArtAug can improve the visual quality of generated images, but that does not guarantee they are useful for your classifier. Synthetic data can help, have no effect, or hurt if it does not match your real data distribution. Always check against the real test set.
- Generated images can be off-class. Filtering and manual spot-checks are recommended.
- FLUX.1-dev is released under a non-commercial license. Check the terms before commercial use.
